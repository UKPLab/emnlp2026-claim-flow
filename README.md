# ClaimFlow Dataset (Preview Version)

## Overview

ClaimFlow is a dataset designed to support the study of scientific claims and their relationships across research papers.

This repository contains a preview version of the ClaimFlow dataset. The preview is intended solely for research discussion, evaluation, and feedback purposes.

The dataset shared here is only a subset of the full ClaimFlow resource and does not represent the complete dataset that will accompany the forthcoming publication.

## Dataset Version

* Dataset: ClaimFlow
* Version: Preview v0.1
* Status: Unpublished Research Resource
* Owner: Aniket Pramanick

## Contents

* `data/sample_gold_small.jsonl` — Preview dataset.
* `metadata/schema.json` — Description of dataset fields.
* `metadata/dataset_info.json` — Dataset metadata.
